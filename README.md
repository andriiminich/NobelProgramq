# Каталог Нобелівських лауреатів

Адаптивний та доступний вебзастосунок для пошуку і перегляду інформації про
лауреатів Нобелівської премії. Навчальний проєкт у межах курсу «Web Development».

Демо (живі дані): список лауреатів → детальна сторінка про кожного лауреата.

## Призначення

Застосунок дозволяє користувачу:

- шукати лауреатів за іменем;
- фільтрувати за категорією премії (фізика, хімія, медицина, література, мир, економіка);
- фільтрувати за статтю;
- сортувати результати (спочатку новіші / старіші);
- перегортати сторінки результатів (пагінація);
- переглядати детальну інформацію про лауреата: дати життя, категорії, мотивацію
  нагородження, організації та зовнішні посилання.

Формат застосунку — MPA (Multi-Page Application) із двох сторінок:

1. `index.html` — каталог (список лауреатів).
2. `details.html?id=<id>` — детальна інформація про лауреата.

## Технології

- **HTML5** — семантична розмітка (`header`, `nav`, `main`, `section`, `article`, `footer`, `dl`).
- **CSS** — CSS Variables, Flexbox/Grid, responsive design (mobile-first), темна/світла теми.
- **TypeScript** — типізація API-відповідей та коду застосунку.
- **JavaScript (ES modules)** — асинхронність, DOM, події.
- **Vite** — збірка, dev-сервер та статичний експорт.
- **Vitest** — модульні тести.
- **ESLint + Prettier** — якість коду та форматування.

## Використаний API

[Nobel Prize API](https://www.nobelprize.org/about/developer-zone-2/) (версія 2.1,
без API-ключа):

- `GET https://api.nobelprize.org/2.1/laureates` — список лауреатів із підтримкою
  параметрів `name`, `nobelPrizeCategory`, `gender`, `offset`, `limit`.
- `GET https://api.nobelprize.org/2.1/laureate/{id}` — дані одного лауреата.

Оскільки Nobel Prize API не містить зображень, фото лауреатів додатково підтягуються
з Wikipedia (pageimages API) за полем `wikipedia.slug`. Якщо фото немає — показуються ініціали.

## Запуск

Потрібен [Node.js](https://nodejs.org/) версії 18 або новішої.

```bash
# 1. Встановити залежності
npm install

# 2. Запустити dev-сервер (http://localhost:5173)
npm run dev

# 3. Зібрати виробничу версію (папка dist/)
npm run build

# 4. Переглянути збірку локально
npm run preview
```

### Перевірки

```bash
# Модульні тести
npm test

# Тести в режимі спостереження
npm run test:watch

# Лінтинг
npm run lint

# Форматування коду
npm run format
```

## Реалізовані рішення (короткий технічний звіт)

- **Семантичний HTML5.** Логічна структура з орієнтирами (`<header>`, `<main>`,
  `<nav>`, `<footer>`), описовими заголовками та `aria-label` для інтерактивних блоків.
- **Адаптивний інтерфейс.** Grid/Flexbox, `clamp()` для типографіки, контрольні точки
  `820px` і `480px`; сітка карток через `auto-fill`/`minmax`.
- **CSS Variables і теми.** Усі кольори й відступи задані токенами; темна тема реалізована
  через атрибут `data-theme` і зберігається у `localStorage` (враховує `prefers-color-scheme`).
- **Доступність (WCAG 2.2).** Skip-link, видимий фокус, `aria-live` для динамічних станів,
  `role="alert"` для помилок, мітки у формах, `prefers-reduced-motion`, контрастні кольори.
- **REST API.** Асинхронні запити через `fetch` з `AbortController` (скасування застарілих
  запитів), таймаут очікування відповіді, типізовані відповіді, централізована обробка помилок.
  Сортування виконується на клієнті, оскільки серверний параметр `sort` у Nobel Prize API
  зависає на великій колекції.
- **Loading/error/empty states.** Скелетони під час завантаження, блок помилки з кнопкою
  «Спробувати ще раз», порожній стан для відсутніх результатів.
- **TypeScript.** Повна типізація API, суворі налаштування компілятора (`strict`,
  `noUnusedLocals`, `noUnusedParameters`).
- **Тестування.** Модульні тести для URL-білдера, форматування, екранування HTML та
  компонентів розмітки.
- **Безпека.** Всі дані з API екрануються перед вставкою в DOM (`escapeHtml`), що запобігає XSS.

## Як перевірити доступність і адаптивність

- **Адаптивність.** У браузері відкрийте DevTools (F12) → іконка пристрою
  (`Ctrl+Shift+M`) і змінюйте ширину. Сітка карток, фільтри, шапка та детальна
  сторінка перебудовуються на контрольних точках 820px і 480px.
- **Клавіатура.** Натискайте `Tab`: спочатку зʼявляється «Перейти до основного вмісту»
  (skip-link), далі навігація, перемикач теми, пошук, фільтри, картки, пагінація.
  `Enter`/`Space` активують елементи, видиме підсвічування фокуса працює скрізь, а
  після перегортання сторінки фокус повертається на активну сторінку пагінації.
- **Скрин-рідер.** Увімкніть Narrator (`Win+Ctrl+Enter`) або NVDA. Оголошуються
  заголовки та орієнтири, мітки полів, кількість результатів (`aria-live`), стан
  завантаження та помилки (`role="alert"`).

## Публікація

Проєкт зібрано через `npm run build` у папку `dist/`. Для публікації підходить будь-який
статичний хостинг:

- **Vercel / Netlify** — build command `npm run build`, output directory `dist`.
- **GitHub Pages** — завантажити вміст `dist/` (наприклад, через `gh-pages`).

> Примітка: Nobel Prize API підтримує CORS, тому запити працюють прямо з браузера.
